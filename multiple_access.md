# Multiple access and network issues

Source: Section VIII of the original report and the comparison illustration on page 4.

| Technique | Resource sharing | Principal trade-off |
|---|---|---|
| OMA | Separate time or frequency resources | Simpler separation; potentially less efficient resource use |
| NOMA | Shared resources, differentiated by power or code | Interference separation and receiver complexity |
| SDMA | Spatial separation using beamforming/MIMO | Depends on spatial separation and channel information |
| RSMA | Common and private message components | Flexible interference management with additional processing |

Satellite mobility and long feedback delays can make accurate channel state information difficult to obtain. The paper discusses these approaches as candidates for NTN research, not as a claim that all are standardized or deployed 5G NTN access modes.

No comparative throughput, fairness or spectral-efficiency simulation was supplied.
